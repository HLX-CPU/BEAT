# BEAT 买家上手（3 分钟）

> 这页给第一次使用 BEAT 的买家；不需要改配置、不需要读开发文档。
>
> **2.2.125 更新**：本条汇总 2.2.120—2.2.125。文件交付按真实字节与 SHA-256 核验，目标点名的文件不再因方案漏登记被判“来源不明”；失败后可用 `node src/cli.mjs release <任务号>` 只重排被隔离的小任务、不重放写入；文件夹授权可用 `node src/cli.mjs folders list/add/remove`；暂停的搭档不会被静默换人，取消未调用模型时明确“未产生费用”，轮数被调整会说明请求值与实际值；`wait_seconds` 非法值在派发前拒绝，`beat_get` 可用 `fields` 精简返回。

## 1. 安装（Windows 10/11 x64）

1. 运行 **BEAT-Setup-x64.exe**，按向导完成；也可以解压 **BEAT-Portable.zip** 后双击 **BEAT.exe**。
2. 如果 Windows 弹出“Windows 已保护你的电脑”：点 **更多信息 → 仍要运行**。
   本安装包**未做代码签名**，这是正常提示；校验文件是否完整请看随包的 **SHA256SUMS.txt**。
3. 安装完成后双击桌面/开始菜单的 **BEAT**，看板会在浏览器打开：<http://127.0.0.1:8765>。

## 2. 第一次打开先看三件事

1. **顶部搭档卡片**：“在线”表示已连接；“工具能力待验证”表示尚未验证操作能力，“文件交付有通过记录”表示已有成功文件任务。显示“离线”时按卡片上的中文原因处理。
2. **右上角版本号**：确认你装的是最新版；需要升级时直接运行新安装包，会保留任务记录和设置。
3. **没有搭档也能用**：可在顶部「＋」接入任意 OpenAI 兼容模型（拓展坞），作为执行搭档。

## 3. 三个最常用动作

- **只问一句**：在「今天想完成什么？」里写问题，点「开始」。普通问题直接回答，不展开方案。
- **让它动手**：同一输入框写“在桌面新建通知.txt，内容是明天下午三点开会”。它会自动解析桌面等真实文件夹并核验文件；不需要你填路径。
- **多搭档协作**：仍在同一个输入框写需求，例如“请多位搭档共同讨论……”；开始前会说明处理方式和额外调用。也可以展开「高级协作选项」手动安排。
- **开始另一件事**：点「开始新需求」。已有任务、会话和文件都会保留，不需要填写或清空会话号。

## 4. 怎么看花了多少

- 任务详情先显示调用次数、用时与成果；「完整过程、用量与诊断」里保留详细计量。**记录用量沿用各接口的统计口径**：Codex 的输入与总量包含缓存，当前 DeepSeek 原生计量使用新增输入加输出、缓存另列；历史记录保留当时统计口径。不同模型的记录不能直接比较费用，也不能将缓存与汇总用量直接相加或相减；拓展坞以接口返回为准。
- 默认有讨论/执行/单任务三层预算，达到上限前会停下来问你要不要继续；也可以在看板「设置 → 高级设置」按任务调整。
- 真实费用以提供方（Codex / DeepSeek / 拓展坞）账单为准；看板只做本地计量与审计。
- 软件购买价与模型额度分开，使用本机账号或 API 时可能消耗其额度或产生费用；看板不会把 token 数直接当成人民币金额。

## 5. 遇到问题

- 搭档离线：按卡片上的中文原因处理；修好后点「恢复」。
- 任务失败：任务详情会说明“文件是否已改 / 是否产生费用 / 下一步”；已有文件不会自动删除。
- 已有成果只差核验：点击「继续检查已有成果」，不会重新制作文件。
- 文件内容仍有缺项：日志确认仅涉及文件操作时，可以点击「补齐未完成的文件内容」，沿用原会话先读回再修正。未知电脑输入不会自动重放。
- 查看成果：任务顶部显示成果、预览、打开成果、打开所在文件夹和复制路径；检查点留在完整过程里。
- 代理开关或端口变化：BEAT 在任务之间自动更新网络出口，无需重启；进行中的任务不会被强制中断。
- 想看记录：所有任务都有任务号、日志和 `data/reports/<任务号>.md`；安装版数据在 `%LOCALAPPDATA%\BEAT`，便携版在 `portable-data\`。

## 6. 隐私与数据

- 密钥只保存在本机数据目录的 `secrets.local.json`，不会上传。
- 卸载默认保留任务记录与设置；加 `--purge` 才会删除数据。
- 关闭程序：`关闭BEAT.cmd`（正在执行任务时会确认，已写入文件保留）。

## 7. 自检

双击 **自检.cmd**（便携版/安装目录均有）：它在专属副本里运行，不会改动你的设置和任务记录，结果在 `portable-data/self-tests`。
